Rotoscoping Workflow

Frame-by-frame rotoscoping process used to recreate a dance performance in ibis Paint X, preserving the dancer's movements, timing, and overall motion.

01 / Frame Extraction

  • Source Video:Select the recorded dance performance as the reference footage.
  • Extract Frames:Convert the dance video into individual image frames for detailed tracing.
  • Import Frames:Load the extracted frames into ibis Paint X as the reference sequence.

02 / Frame-by-Frame Tracing

  • Reference Layer:Use each extracted frame as the guide for drawing the dancer's pose.
  • Manual Trace:Trace every frame individually in ibis Paint X to capture each dance movement.
  • Motion Flow:Maintain consistent proportions and smooth transitions between consecutive frames.

03 / Animation Export

  • Hide References:Remove the original dance video frames, leaving only the completed traced artwork.
  • Playback Check:Preview the traced sequence to verify smooth and natural dance animation.
  • Export Output:Export the completed rotoscoped dance animation as the final video.
